# Information Security Policy

**Status:** Planned template — adapt and approve for the intended organization before operational use.

## 1. Purpose and scope

State the security objectives, covered people, systems, and information, and any exclusions.

## 2. Roles and responsibilities

Identify policy ownership, user responsibilities, and escalation contacts using role names rather than personal details.

## 3. Minimum requirements

Define requirements for access control, acceptable use, data handling, endpoint protection, secure development, vulnerability management, backups, and incident reporting.

## 4. Exceptions and enforcement

Describe documented exception approval, review, and proportionate enforcement.
